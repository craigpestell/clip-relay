# clip-relay

Copy text on your computer and send it to your phone. The phone shows a notification with a copy button that puts the text on the phone's clipboard. Think of Chrome's "send to your devices", but for any text.

**Stage:** idea. The team is evaluating whether enough people would adopt it to be worth building. No code yet.

The team handbook is in [docs/team/README.md](docs/team/README.md).
